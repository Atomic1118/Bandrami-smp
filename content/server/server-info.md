title: Server Info
---

Bandrami SMP is a Minecraft Lifesteal server running the latest version of Java, created as a private and community-focused server for players to enjoy survival, PvP, and the chaos that comes with Lifesteal gameplay.

The server was started by ZEKO_PX with the goal of creating a fun place for the community to play Minecraft together, while keeping the server organized and enjoyable for everyone.

Bandrami SMP features a variety of server plugins that add extra gameplay and quality-of-life features, including Lifesteal, shops, auctions, and Simple Voice Chat. These features are designed to make the server more interactive while still keeping the main Minecraft experience at the center.

Since this is a community server, respecting other players and following the server rules is important. The staff team is here to help players, handle issues, manage donations, and keep the server running smoothly.

Bandrami SMP is intended to be a place where players can build, explore, fight, trade, make alliances, create rivalries, and enjoy the server together. Whether you're here to survive, PvP, build something cool, or simply mess around with friends, there's always something happening.

Bandrami SMP is a community built around Minecraft, friendship, competition, and a little bit of Bandrami
